# Tamil Nadu College Compass — UI Demo

A small, self-contained Flask prototype for demonstrating a Tamil Nadu college discovery experience.

## What's included
- Four streams: Engineering, Agriculture, Medical, Arts & Science.
- Search by college name, city or district.
- Stream filtering and college profile pages.
- Sample courses and facilities.
- A deterministic demo chatbot (not an AI service).
- SQLite sample database bundled with the project.
- No registration, login, payment, or personal-data collection.

All colleges and sample records are fictional demonstration data. They are not recommendations and must not be treated as official facts.

## Run locally (Windows PowerShell)

```powershell
cd path\to\TamilNaduCollegeCompass
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Vercel deployment

1. Push this folder to a new GitHub repository.
2. Import that repository into Vercel.
3. Set Root Directory to `./`.
4. Select Flask if available; otherwise use automatic Python/Flask detection.
5. Do not set an Output Directory override or a Node.js build command.
6. Deploy.

`index.py` exports the Flask app. The bundled SQLite database is opened read-only. This demo does not write to the database, so search and profile browsing work without persistent storage. The chatbot is a demo endpoint and does not store conversations.

If Vercel does not detect Flask, inspect the deployment build/runtime logs before adding configuration. Do not set `public` as the output directory.

## Important limitations
- Sample colleges, course names and facilities are fictional.
- No real admission guidance, fees, cutoffs, seat availability or counselling dates are provided.
- Chat answers are predefined examples, not generated by an AI model.
- Database is read-only; there are no persistent favourites or user accounts.
- This is a demonstration prototype, not a production service.
